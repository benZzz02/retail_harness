# τ-bench Retail one-turn LLM pilot: test/0–9

Date: 2026-09-13  
Model: `gpt-5.6-luna` (`reasoning=low`)  
Environment: external legacy `tau-bench` Retail  
Harness: `TauHarnessRuntime` + `CodexCliProvider`  
Maximum steps: 20 per task

## Protocol

- Ran test indices 0 through 9 once each.
- The provider received the upstream Retail policy, 16 tool schemas, the task
  instruction, and accumulated tool observations.
- Gold actions, expected outputs, and expected terminal hashes were not placed
  in the provider context.
- Because no live user simulator was attached, the initial request was treated
  as final authorization and the terminal assistant message was recorded
  without advancing the HUMAN stdin simulator.
- Important: the upstream `task.instruction` was supplied directly. In the
  official protocol this text drives a user simulator and can contain future
  conditional behavior. Therefore this pilot is not an official benchmark run.

## Failure analysis

- Task 5 requires two confirmation-driven user changes: the expected terminal
  action returns only the water bottle, while the one-turn agent exchanged both
  initially requested items.
- Tasks 6–8 expect the user to narrow the request after confirmation to only the
  desk lamp. The model chose the correct lamp variants but also exchanged the
  water bottle.
- Task 9 has the same missing-confirmation error and additionally selected the
  USB high-brightness lamp (`9083642334`) instead of the preferred available AC
  adapter variant (`7624783998`).

The 5/10 number mixes one genuine option-ranking error with a systematic
protocol gap. It must not be presented as an official τ-bench success rate.

## Required next step for official evaluation

Connect a live user simulator and expose only the simulator's current utterance
to the agent. The loop must alternate `agent -> tool/user -> agent`, preserve
confirmation and user-change turns, and let the upstream environment terminate
the conversation before calculating pass/fail. Prefer migrating this work to
the maintained τ³ repository before reporting a full benchmark number.
